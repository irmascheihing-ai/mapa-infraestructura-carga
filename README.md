# Mapa de infraestructura de carga — Chile

Mapa interactivo de las 346 comunas y 16 regiones de Chile: elige qué insumo
colorear (población, PIB, potencia instalada, cargadores públicos/privados)
y qué redes viales mostrar (Ruta 5, Carretera Austral, Ruta 9, pasos
internacionales, conexiones a ciudades).

Generado a partir del pipeline de datos del proyecto
[Proyecciones_IC](https://github.com/irmascheihing-ai/Proyecciones_IC)
(privado). Ver `docs/index.html` allá para el generador
(`Código/generar_datos_mapa.py` + `Código/generar_mapa_html.py`).

**Publicado en GitHub Pages:** se habilita en Settings → Pages → Deploy from
branch → `main` → `/ (root)`.
